# Central Park Squirrel Census (pandas)

Counts the squirrels in New York's 2018 Central Park Squirrel Census by fur colour.

## How it works

- Reads the census CSV with pandas.
- Counts the grey, cinnamon and black squirrels.
- Writes the totals to `squirrel_count.csv`. `weather-data.csv` is a second practice dataset.

## Tech

Python · pandas

## Run

```bash
pip install pandas
python main.py
```
