# Kanye Quotes (Tkinter + API)

A small desktop app that shows a random Kanye West quote. Click his face to get a new one.

## How it works

- Fetches quotes from the public [kanye.rest](https://api.kanye.rest) API.
- Displays each quote on a speech-bubble canvas in a Tkinter window.

## Tech

Python · Tkinter · requests

## Run

```bash
pip install requests
python main.py
```
