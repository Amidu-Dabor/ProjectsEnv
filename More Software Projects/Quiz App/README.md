# True/False Quiz

A command-line true/false quiz on computer-science trivia, with a running score and a final percentage.

## How it works

- `data.py`: the question bank, in the format of the Open Trivia Database API.
- `question_model.py`: a `Question` class.
- `quiz_brain.py`: a `QuizBrain` class that asks questions, checks answers and keeps score.

## Tech

Python (object-oriented design)

## Run

```bash
python main.py
```
