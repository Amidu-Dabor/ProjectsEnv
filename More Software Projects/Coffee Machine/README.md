# Coffee Machine (OOP)

A command-line coffee machine that serves espresso, latte and cappuccino, checks its ingredients, takes coins and gives change.

## How it works

- `menu.py`: drinks, recipes, prices and starting resources.
- `coffee_maker.py`: checks for enough water, milk and coffee, then makes the drink.
- `money_machine.py`: counts quarters, dimes, nickels and pennies, and handles change and profit.
- Type `report` to see resources and takings, or `off` to stop.

## Tech

Python (object-oriented design)

## Run

```bash
python main.py
```
