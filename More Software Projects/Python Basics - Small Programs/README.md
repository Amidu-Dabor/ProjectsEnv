# Python Basics: Small Programs

Short single-file programs written while learning Python fundamentals: functions, loops, conditionals, lists, dictionaries and the `random` and `turtle` modules.

| File | What it does |
|---|---|
| `blackjack.py` | Command-line Blackjack against the computer: deals cards, scores aces as 11 or 1, and compares hands |
| `caesar_cipher.py` | Encodes or decodes a message with a Caesar cipher shift |
| `higher_lower_followers.py` | "Higher or lower" game: guess which of two accounts has more followers. It needs `art.py` and `game_data.py` (logos and account data), which aren't included |
| `number_guessing.py` | Guess a number from 1 to 50, with an easy or hard difficulty level (more or fewer attempts) |
| `leap_year.py` | Checks whether a year is a leap year, and whether February has 29 days |
| `turtle_race.py` | Bet on one of several coloured turtles, then watch them race across the screen |
| `dot_painting_turtle.py` | Paints a grid of coloured dots, in the style of a Damien Hirst spot painting, using colours extracted from an image with `colorgram` |

## Run

```bash
python blackjack.py
```

`dot_painting_turtle.py` needs `pip install colorgram.py` and an `image.jpg` in the same folder.
