# Form-Filling Bot (Selenium)

Automates filling in and submitting a sign-up form in Chrome, and reads data from a live page.

## How it works

- Opens a practice sign-up page, types a first name, last name and email, and clicks the sign-up button.
- Also practises navigating Wikipedia: clicking a link and typing into the search box.

## Tech

Python · Selenium WebDriver · Chrome

## Run

```bash
pip install selenium
python main.py
```
