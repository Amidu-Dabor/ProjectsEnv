# Pong

The classic two-player Pong game.

## How it works

- `paddles.py`: left and right paddles moved with **W/S** and **Up/Down**.
- `ball.py`: bounces off the walls and paddles and speeds up after each hit.
- `scoreboard.py`: keeps each player's score.
- `main.py`: the game loop.

## Tech

Python · turtle (standard library)

## Run

```bash
python main.py
```
