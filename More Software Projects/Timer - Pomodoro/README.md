# Pomodoro Timer (Tkinter)

A Pomodoro productivity timer: 30-minute work sessions with 5-minute short breaks and a 20-minute long break.

## How it works

- Counts down on a tomato image and changes the title colour for work and break periods.
- Adds a ✔ for each completed work session.
- **Reset** stops the timer and clears progress.

## Tech

Python · Tkinter

## Run

```bash
python main.py
```
