### **2. Machine Learning Projects**

#### **Data Preprocessing**
- I implemented several techniques for cleaning (handling missing values, encoding categorical data, splitting the data, feature scaling, feature selection), normalizing, and transforming raw data into structured formats suitable for analysis.
- Frameworks/Libraries/Tools/Techniques used: scikit-learn, numpy, pandas, and other great tools and techniques.

#### **Regression**
- Builds models for predicting continuous outcomes, such as house prices or sales figures, leveraging algorithms like Simple Linear Regression, Multiple Linear Regression, Polynomial Linear Regression, Support Vector Regression (SVR), Decision Tree Regression, and Random Forest Regression.
- I explored these algorithms on varying datasets like Salary Prediction Experience Dataset, Startup Profit vs Investment Dataset, Salary Benchmarking Dataset.
Algorithms implemented for each use case:
1. Simple Linear Regression -> Salary Prediction Experience Dataset
2. Multiple Linear Regression -> Startup Profit vs Investment Dataset
3. [Polynomial Linear Regression, Support Vector Regression (SVR), Decision Tree Regression, and Random Forest Regression] -> Salary Benchmarking Dataset
- The goal of these algorithms in this use case (salary benchmarking) is to predict the previous salary of a new recruit based on relevant features and compare it with their expected salary, enabling informed decision-making in salary benchmarking and negotiation processes.
- Frameworks/Libraries/Tools/Techniques used: scikit-learn, numpy, pandas, matplotlib, and seaborn.

#### **Classification**
- Developes classifiers to categorize data into distinct groups, using models such as logistic regression, KNearest Neighbours, Support Vector Machine (SVM), Kernel SVM, Naive Bayes, Decision Tree Classification, and Random Forest Classification.
- I explored these algorithms on a social network ads dataset to predict the probability that a customer will purchase a product or will not purchase a product.
- Frameworks/Libraries/Tools/Techniques used: scikit-learn, numpy, pandas, matplotlib, and seaborn.

#### **Clustering**
- Clustering can be used to implement unsupervised learning techniques like KMeans and hierarchical clustering for grouping similar data points, such as customer segmentation.
- I implemented the above-mentioned unsupervised learning techniques, including agglomerative hierarchical clustering, to group customers based on their annual income and spending scores.
- Frameworks/Libraries/Tools/Techniques used: scikit-learn, the elbow method, scipy, pandas, matplotlib, and seaborn.

#### **Association Rule Learning**
- Discovers relationships between variables in large datasets, applying techniques like Apriori and Eclat for market basket analysis.
- I implemented Apriori and Eclat rules for market basket optimisation.
- Apriori - focuses on Support, Confidence, and Lift.
- Eclat - focuses only on support.
- Frameworks/Libraries/Tools/Techniques used: apyori, and pandas.

#### **Reinforcement Learning**
- Explored decision-making models, such as Upper Confidence Bound (UCB) and Thompson Sampling, where agents learn optimal behaviors through rewards and penalties.
- I implemented these decision-making models on an ads dataset to determine which ad performs best (i.e., gets the most clicks, obtained from Ads Dataset) and display it more often to maximize engagement.
- Frameworks/Libraries/Tools/Techniques used: Upper Confidence Bound (UCB) - uses a confidence interval to estimate the best ad, Thompson Sampling - uses a probability distribution to sample the best ad, pandas, numpy, matplotlib, and seaborn.

#### **Natural Language Processing (NLP)**
- NLP techniques can be applied for tasks like text classification, sentiment analysis, and language translation.
- I implemented NLP techniques on a restaurant review dataset to predict whether a single review for a restaurant is positive or negative.
- Frameworks/Libraries/Tools/Techniques used: scikit-learn (used a classifier model and more), pandas, numpy, matplotlib, seaborn, nltk, and re (regular expressions for removing special characters).

#### **Deep Learning**
- Leverages neural networks to solve complex problems, including image recognition and time-series forecasting, using frameworks like TensorFlow and Keras.


#### **Dimensionality Reduction**
- Reduces the complexity of datasets while preserving essential information, enhancing computational efficiency.
- Implemented techniques such as Principal Component Analysis (PCA), Linear Discriminant Analysis (LDA), and Kernel PCA on a wine dataset to segment customers based on the appropriate quality and type of wine they would prefer.
- Frameworks/Libraries/Tools/Techniques used: scikit-learn, pandas, numpy, matplotlib, and seaborn.

#### **Model Selection Boosting**
- Used to optimize model performance using ensemble methods, hyperparameter tuning, and techniques like XGBoost and grid search.
- I implemented Grid Search Algorithm and K-Fold Cross Validation on a Social Network Ads dataset to predict the probability that a customer will purchase a product or will not purchase a product.
- I implemented XGBoost on a cancer dataset to class whether a cancer is malignant or benign.
- Frameworks/LibrariesTools/Techniques used: Xgboost, scikit-learn, K-Fold Cross Validation, Grid Search Algorithm, and pandas.
