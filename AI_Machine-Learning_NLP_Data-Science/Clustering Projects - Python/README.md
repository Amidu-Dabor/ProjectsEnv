# Mall Customer Segmentation (Clustering)

Groups shopping-mall customers by **annual income** and **spending score** so a business can target each group differently.

## What's inside

- **K-Means:** chooses the number of clusters with the elbow method, then plots the five customer groups.
- **Hierarchical (agglomerative) clustering:** chooses the number of clusters from a dendrogram, then plots the groups.

Data: `Mall_Customers.csv` (customer ID, gender, age, annual income, spending score).

## Tech

Python · scikit-learn · SciPy · pandas · Matplotlib · Seaborn

## Run

Run the notebooks with Jupyter (`pip install jupyter pandas numpy matplotlib seaborn scikit-learn`), from inside their own folder so the CSV paths resolve.
