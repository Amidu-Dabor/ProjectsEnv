# Wine Classifier: Comparing Six Models

Trains six classifiers on the Wine dataset with one reusable `WineClassifier` class, then compares them side by side.

## Results (test set, from the saved run)

| Model | Accuracy |
|---|---|
| Random forest | 88.9% |
| K-nearest neighbours | 88.9% |
| Naive Bayes | 83.3% |
| Decision tree | 80.6% |
| Support vector machine | 77.8% |
| Logistic regression | 72.2% |

For each model the notebook shows a classification report, a confusion matrix and decision-boundary plots.

## Tech

Python · scikit-learn · pandas · Matplotlib · Seaborn

## Run

Open `wine_classifier.ipynb` in Jupyter.
