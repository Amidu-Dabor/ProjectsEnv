# Regression Models (Python and R)

Predicting continuous values with five regression algorithms, each implemented in both Python and R.

## Projects

| Project | Data | Models |
|---|---|---|
| Salary from years of experience | `Salary_Data.csv` | Simple linear regression |
| Salary from job level | `Position_Salaries.csv` | Polynomial regression, support vector regression (SVR), decision tree, random forest |
| Start-up profit from spending | `50_Startups.csv` | Multiple linear regression (R&D, administration and marketing spend, state) |

`Using Python/Best Regression Model Selection/General Evaluation Templates/` holds reusable templates that compare all models on any dataset by R² score.

## Tech

Python (scikit-learn, pandas, Matplotlib) · R

## Run

Run the notebooks with Jupyter (`pip install jupyter pandas numpy matplotlib seaborn scikit-learn`), from inside their own folder so the CSV paths resolve. Run the `.R` scripts in RStudio.
