# HR Analytics Dashboard (Tableau)

A two-page Tableau dashboard for an HR team: a **summary** view of headcount, hiring, terminations and demographics, and a **details** view listing employee records with filters.

## What's inside

| File | Contents |
|---|---|
| `HR Analytics Dashboards.twbx` | The packaged Tableau workbook (open with Tableau Desktop or Tableau Public) |
| `HR Analytics Dashboard.pdf` | An export of both dashboard pages |
| `Dashboard Frame - Figma.png`, `Dashboard Frame 2 - Figma.png` | Layout designs made in Figma before building |
| `Tableau-HR-Project-Materials/` | The HR datasets (an original and a version adapted to Kenyan names and locations), icons, backgrounds and wireframe mock-ups |

## Tech

Tableau · Figma · draw.io
