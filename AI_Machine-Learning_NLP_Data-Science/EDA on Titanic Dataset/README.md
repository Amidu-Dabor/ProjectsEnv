# Titanic: Exploratory Data Analysis

A structured exploratory data analysis of the Titanic passenger data, looking at which factors (sex, class, age, fare, family size) relate to survival.

## Structure

The notebook is organised as classes for each stage: `TitanicEDA`, `DataQualityChecker` and `MissingValueHandler`. It walks through:

1. Initial exploration
2. Data quality checks (duplicates, consistency)
3. Missing-value patterns and handling
4. Univariate, bivariate and multivariate analysis
5. Conclusions

A full write-up is in `Data and AI - Titanic Exploratory Data Analysis.pdf`.

## Tech

Python · pandas · NumPy · Matplotlib · Seaborn · missingno · SciPy

## Run

Open `EDA_on_Titanic_Dataset.ipynb` in Jupyter from this folder (`pip install missingno` if needed).
